Conventions. Ledger citations are `results.tsv` plus the row's `experiment_id`; report paths are relative to classic's
`autoresearch/`. Source paths are classic paths at `b2d945a`. This repository has no application checks yet, so a
destination is the bead that must build the check: its ID, plan key and the quoted acceptance item. "Classic test" names
a test that exists in classic today and documents the behaviour; it is not a destination check here. Status words
(keep, inconclusive, proposed, discard, blocked, baseline, candidate) are the ledger's recorded verdicts, not
requalification.
