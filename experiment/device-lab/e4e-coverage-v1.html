Photo pipeline coverage

16 September 2026 · Whole-pipeline research; per-run evidence determines qualification.

Autoresearch covers the complete photo workflow: local alignment, actual e4e encoding, full1024 reconstruction, caching, morphs and export. The historical synthesis-only runs below did not execute e4e; new photo experiments must record each executed stage and its result.

Mac ARM64 native Torch CPU passed actual e4e reference, repeat, no-face and malformed-input checks. This does not qualify browser, other architectures, or the complete photo pipeline.

Required evidence ⓘ

Image decode and alignment → actual e4e → full1024 reconstruction → original-cache reuse → repeat → failure recovery. Record OS, architecture, browser, actual providers and model hashes independently. Phone experiments must measure the complete workflow, including worker/model lifetimes, overlapping allocations, peak memory, cancellation and recovery. Compare memory and speed tradeoffs using bounded, instrumented candidates; a product-admission flag must not prevent collecting experimental evidence.
